# Engine rules: running list

One list, numbered in order. A new rule takes the next number. **No rule is ever deleted.** A rule proven false is struck through, with a note saying what proved it false and where.

The master log is `engine-rules.txt`, kept outside the repo. This list was rebuilt from code comments and commit messages on 2026-11-12, so check it against that log. Where the wording comes only from a commit message, it says so.

| 21 | **Carrier cancels memory (lattice), build spec R-A.** Each whole pixel's worth of carrier (3 units) at a site cancels one conserved unit on each cell that holds one. Every cancelled memory unit uses up one carrier unit, so the two annihilate one for one and nothing is created. The only number is the cell count, as in rule 6. This is the base-lattice counterpart of rule 11. Switch: `feedback=cancel` (rule 6 is `feedback=reinforce`, the same as `gravity=on`). Logged 2026-11-12, before any run. Result 2026-11-12: flashing goes to 0 in all 4 settings, see results/rule21-2026-11-12. | grid3.zig, engine.js | active (switch) |
| 22 | **Exclusion on the pattern (lattice), build spec R-B.** A flash may not display a pattern that any of its 6 neighbours is showing. A blocked flash **waits**: the pixel doesn't flash that tick, keeps its pattern and keeps its memory, and tries again next tick. No new number. This applies to every flash, the tick-0 kick included. Sync checks neighbours as they were at the start of the tick; sweep checks them as they are when the pixel's turn comes. "Same state" = pattern (Jono, 2026-11-12). Switch: `exclusion=on`. Logged 2026-11-12, before any run. Result 2026-11-12: one_cell and flip_all jam (flashing 0 by about tick 20); hold drops from 98% to a steady 28–40%; no shells. See results/rule22-2026-11-12. | pixel.zig, grid3.zig, engine.js | active (switch) |
| 23 | **Three carriers, each conserved separately (lattice), build spec R-C.** The carrier splits into weak, EM and strong channels. Selection follows the triangle note (by charge): a neutrino pixel (0 filled) selects weak only; down and up quark pixels (1 or 2 filled) select EM + weak + strong; an electron pixel (3 filled) selects EM + weak. At a flash, the released conserved share is split equally among the channels the pixel selects *after* flashing (a count, no constant). Each channel spreads like rule 5 (one hop per tick, lost at the box edge) and is conserved on its own; channels never exchange. Response reuses rule 6, per channel: each whole pixel's worth (3 units) of channel c at a site reinforces every cell of the shown pattern, but **only if the pixel there selects c**. Otherwise the carrier passes through untouched. Rule 23 replaces the single carrier and rule 6 while it's on. "Separately" = Jono, 2026-11-12. Switch: `channels=on`. Logged 2026-11-12, before any run. Result 2026-11-12: keeps the world flashing (like rule 6); neutrino pixels rarest and fastest-flashing; quarks absorb all three channels equally, so not dominantly strong as in the triangle; one seed had a core 6× brighter than outside. See results/rule23-2026-11-12. | grid3.zig, engine.js | active (switch) |

| 24 | **Motion (lattice), PLAN-fields F-0.** After the carrier step, each pixel that flashed this tick moves one hop toward the neighbour site holding the most carrier (total over channels if rule 23 is on), but only if that is more than its own site holds. It moves by swapping its whole state (pattern, memory, reinforcement) with the pixel at that site, which must not have flashed this tick. Sites are taken in index order; a site that has already swapped this tick doesn't swap again. Ties go to the first neighbour in order (+x, −x, +y, −y, +z, −z). Carrier stays where it is. No new number. **Default, Jono to confirm** (who moves, toward what, and whether memory travels with the pattern). Switch: `motion=on`. Logged 2026-11-14, before any run. Result 2026-11-14: pixels move (up to about 5,000 swaps per tick); the core comes apart, its pixels drifting outward toward the carrier piled up outside it (29–57% leave the core), except flip_all · sweep, which nearly stops flashing. See results/rule24-2026-11-14. | grid3.zig, engine.js | active (switch) |
| 25 | **Signed EM field (lattice), PLAN-fields F-1.** Each tick, after the carrier step, every pixel adds its charge to a signed field φ at its own site. Charge is in thirds, by filled-cell count: neutrino 0, down −1, up +2, electron −3. φ then spreads like rule 5: all of it, one hop, 1/6 to each neighbour, lost at the box edge. **With rule 24 on**, a charged pixel that flashed moves toward the neighbour where q·φ is lowest, if that is lower than at its own site, so opposite charges attract and like charges repel. Neutral pixels keep rule 24's carrier target. φ is separate from rule 23's EM channel, which stays an unsigned amount. No new number. Charge = filled-cell count (default, Jono said "do it" 2026-11-14). Switch: `em=on`. Logged 2026-11-14, before any run. Result 2026-11-14: in every setting opposite charges become neighbours more often and electrons stop clumping (5–7× chance down to 1.5–3.5×), but like-next-to-like is still above chance; the engine's pattern copying outweighs the EM pull. Flashing falls to about 0.02. Longer run (one_cell · sync, core 0, 3,000 ticks): the world goes completely dark by about tick 2,750, while without EM it keeps flashing at 3–4%. See results/rule25-2026-11-14. | grid3.zig, engine.js | active (switch) |
