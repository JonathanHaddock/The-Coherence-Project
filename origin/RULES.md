# Engine rules: running list

One list, numbered in order. A new rule takes the next number. **No rule is ever deleted.** A rule proven false is struck through, with a note saying what proved it false and where.

The master log is `engine-rules.txt`, kept outside the repo. This list was rebuilt from code comments and commit messages on 2026-11-12, so check it against that log. Where the wording comes only from a commit message, it says so.

| 23 | **Three carriers, each conserved separately (lattice), build spec R-C.** The carrier splits into weak, EM and strong channels. Logged 2026-11-12, before any run. Result 2026-11-12: keeps the world flashing (like rule 6); neutrino pixels rarest and fastest-flashing; quarks absorb all three channels equally, so not dominantly strong as in the triangle; one seed had a core 6× brighter than outside. See results/rule23-2026-11-12. | grid3.zig, engine.js | active (switch) |

| 24 | **Motion (lattice), PLAN-fields F-0.** After the carrier step, each pixel that flashed this tick moves one hop toward the neighbour site holding the most carrier (total over channels if rule 23 is on), but only if that is more than its own site holds. Sites are taken in index order; a site that has already swapped this tick doesn't swap again. Ties go to the first neighbour in order (+x, −x, +y, −y, +z, −z). Carrier stays where it is. No new number. **Default, Jono to confirm** (who moves, toward what, and whether memory travels with the pattern). Switch: `motion=on`. Logged 2026-11-14, before any run. See results/rule24-2026-11-14. | grid3.zig, engine.js | active (switch) |
| 25 | **Signed EM field (lattice), PLAN-fields F-1.** Each tick, after the carrier step, every pixel adds its charge to a signed field φ at its own site. Neutral pixels keep rule 24's carrier target. φ is separate from rule 23's EM channel, which stays an unsigned amount. No new number. Charge = filled-cell count (default, Jono said "do it" 2026-11-14). Switch: `em=on`. Logged 2026-11-14, before any run. See results/rule25-2026-11-14. | grid3.zig, engine.js | active (switch) |
| 26 | **Carrier excites (lattice).** After the carrier step, each whole pixel's worth of carrier (3 units) at a site is taken from the field and adds +1 memory (conserved share) to each of the pixel's 3 cells. 3 carrier units become 3 memory units, so carrier + memory is conserved except at the box edge, and a flash's released memory comes back as carrier and then as memory again. It's the mirror of rule 21. The only number is the cell count. Replaces rule 5's "measurement only". Rules 6 and 21 (gravity, cancel), when switched on, take the place of rule 26; rule 23 keeps its own per-channel response. Jono chose "excites" 2026-11-14 and wants it always on: it's the default in the viewers, and `excite=on` in the Zig recorder and Node runners (old runs reproduce with it off). Cause: hearing a mismatch creates memory (rules 1–3), and carrier had been the only drain. See results/rule26-2026-11-14. | grid3.zig, engine.js, pixel-model.js | active (default) |
| 27 | **Hearing conserves (lattice), from the Bak-Tang-Wiesenfeld sandpile, 1987.** Until now a heard flash gave +1 memory to every mismatched cell, memory made from nothing. Instead, a flashing pixel **hands out the memory it releases**, cell by cell. Cell k's released units go to the neighbours whose cell k differs from the shown pattern, dealt one unit at a time in face order (+x, −x, +y, −y, +z, −z), round and round. Matching neighbours still get +1 reinforcement on that cell (reinforcement isn't energy). Units with no mismatched neighbour to go to become carrier at the flashing site (rule 5, or split by rule 23). So memory + carrier is conserved; the only loss is carrier at the box edge. No new number. Jono chose option 1, 2026-11-14. Switch: `conserve=on`. It's on by default in the viewers, together with rule 26. Logged 2026-11-14, before any run. Result 2026-11-14: no runaway; energy (memory + carrier) is conserved; but every one of 96 runs goes quiet within about 100 ticks, because the world holds about 1.5 units per pixel and a flash needs 3. Like a sandpile below critical density, it needs slow driving from outside. See results/rule27-2026-11-14. | grid3.zig, engine.js, pixel-model.js | active (default) |
