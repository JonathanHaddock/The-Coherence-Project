Origin: one pixel, running

This is the actual pixel object (pixel-model.js) that the 3D field is built from. The 3D field is just copies of it wired face to face, and gives the engine's exact results. Here one pixel sits in the middle with six neighbours, which are copies of the same object. The neighbours' outer sides hear a random flash each tick. That is the only made-up part, and it stands in for the rest of the universe.

Cells: lit = filled. Green bars = reinforcement (heard a match), red bars = memory (heard a mismatch). The pixel flashes when its memory reaches 3. Blue = carrier at the site. An arrow from a face = a flash heard (in) or sent (out). A dashed arrow = the face the pixel wants to move through (rules 24/25).
